# AI Social Media Workflow (n8n)

An n8n workflow that turns one topic into ready-to-post content for LinkedIn, Instagram, Facebook, X, TikTok, Threads, and YouTube Shorts. It sends an approval email before anything is published.

## How to use
1. In n8n, go to Workflows → Import from File and choose the JSON file.
2. Reconnect your credentials (LinkedIn, Threads, Gmail, AI model key).
3. Update the approval email address and the brand prompt.
